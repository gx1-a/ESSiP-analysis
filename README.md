# ESSiP analysis code v1.0.0

MATLAB R2022b code supporting the manuscript **“A Shelf-Interior Polynya Bounded by a Grounded Ice Ridge in the East Siberian Sea: Dynamics, Ice Production and Salt Rejection.”**

This repository contains the analysis and figure-generation code. Study data are kept separately.

## Workflow

1. `preprocessing/SNAP_preprocessing_graph.xml` preprocesses Sentinel-1 EW GRD scenes in ESA SNAP.
2. `preprocessing/reproject_to_epsg3413_batch.m` places the SNAP GeoTIFF output on the common EPSG:3413 / 40 m grid and applies the incidence-angle normalization used in the analysis.
3. `01_derive_rough_ice_footprint.m` derives the persistent rough-ice footprint from the 100 processed Sentinel-1 scenes.
4. `02_train_validate_random_forest.m` trains and validates the random-forest classifier from the released labelled training patches and writes `model/RF_model_clean_final.mat`.
5. `03_classify_100_scenes.m` applies the classifier to all 100 scenes.
6. `04_expert_qc.m` is the interactive expert-review tool used to inspect the automatic masks. The author-reviewed FinalMask files used in the manuscript are provided with the study data, so repeating the manual decisions is not required to reproduce the published downstream calculations.
7. `05_heat_budget.m` computes the SAR-constrained potential open-water heat loss, potential ice production, and potential salt rejection.
8. `06_sea_ice_drift.m` retrieves sea-ice displacement and drift for 22–26 March 2026.
9. `07_plot_figure1.m`–`10_plot_figure4.m` reproduce manuscript Figures 1–4.

## Required study data

Place the companion study files in the following locations. The existing MAT files can be used as they are; they do not need to be rewritten into reduced “release” copies.

```text
processed/
    Sentinel1_acquisition_times_20251122_20260430.csv
    Sentinel1_multiyear_acquisitions_FigureS3.csv
    ridge/
        Figure1_SAR_Background.mat          # historical SAR background used by Figure 1(b)

training_patches/
    Cropped_YYYYMMDD_patches.mat        # 10 files; must contain patch_HH
    TrainPatches_YYYYMMDD_mask.mat      # 10 files; must contain TrainingPatches.label

scene_eval_RF_clean/
    manual_qc/
        FinalMask_YYYYMMDD.mat          # author-reviewed masks used in the manuscript
```

The ten RF training dates are `20251213`, `20251219`, `20260109`, `20260122`, `20260223`, `20260323`, `20260404`, `20260412`, `20260416`, and `20260425`.

`05_heat_budget.m` uses grid coordinates embedded in a FinalMask when present. For the original FinalMask files that do not contain grid vectors, it uses the common grid generated by `01_derive_rough_ice_footprint.m`. The FinalMask files therefore do not need to be modified for release.

The following are generated products and do not need to be deposited as input data: `RF_model_clean_final.mat`, automatic `Result4_*.mat` files, rough-ice output files, heat-budget outputs, drift outputs, and the processed Sentinel-1 MAT files (including the five March scenes used by script 06).

## Third-party inputs

The raw/reanalysis products should be obtained from their original providers and cited in the manuscript/Data and Software Availability statement:

- Sentinel-1A/C EW GRD scenes identified by the acquisition manifest;
- ERA5 hourly data required by scripts 05 and 08, placed below `ERA5/`;
- IBCAO v4.2 (`IBCAO/IBCAO_v4_2_400m_ice.nc`) for Figure 1;
- M_Map for Figure 1(a).

See `PREPROCESSING.md` for the Sentinel-1 processing chain and required ERA5 variables.

## Required software

- MATLAB R2022b
- Image Processing Toolbox
- Statistics and Machine Learning Toolbox
- Mapping Toolbox
- ESA SNAP
- M_Map (Figure 1(a) only)

## Reproduction notes

The RF model is intentionally not distributed because script 02 regenerates it from the labelled training data. The large processed Sentinel-1 MAT files are also not treated as archive inputs because they are generated from the source Sentinel-1 products by the supplied SNAP and MATLAB preprocessing chain.
